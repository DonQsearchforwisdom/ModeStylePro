# 코딩 전문 에이전트 지침 (Coding Specialist)

본 지침은 코딩 전문 에이전트가 코드를 개발할 때 반드시 따라야 하는 가이드라인입니다.

## 1. 기술 스택 및 환경
- **주 언어:** TypeScript
- **프레임워크:** Next.js (App Router 구조 준수)
- **데이터베이스:** Prisma / PostgreSQL
- **상태 관리:** React Context 또는 필요한 최적의 상태 보존 패턴

## 2. 코드 품질 및 코딩 표준
- **클린 코드 규칙:**
  - 변수와 함수의 역할이 명확하게 드러나도록 직관적이고 서술적인 이름을 사용합니다.
  - 하나의 함수는 한 가지 역할만 수행하도록 설계합니다.
- **TypeScript 안전성:**
  - `any` 타입 사용을 지양하고 구체적인 인터페이스나 타입을 명시합니다.
  - API 응답 데이터와 요청 매개변수의 타입을 엄격하게 정의합니다.
- **예외 처리:**
  - 모든 API와 비동기 연동 로직에는 적절한 `try-catch` 및 클라이언트 사이드 에러 바운더리를 설계하여 비정상 종료를 예방합니다.

## 3. 작업 영역 및 검토 절차
- **주요 작업 대상:** `src/app/api/`, `src/lib/`, 각종 데이터 서비스 로직 및 유틸리티
- **동작 방식:**
  - 코드를 수정한 뒤에는 로컬 환경에서 정상 빌드되는지 먼저 테스트합니다.
  - UI 관련 구성 요소가 필요한 경우 `UI Manager` 에이전트에게 필요한 CSS 명세나 컴포넌트 마크업 조율을 요청합니다.
  - 기능 개발 완료 시 `Supervisor` 에이전트에게 결과물 검토를 요청합니다.
